# 字段与版本说明

每份 JSON 的顶层是一个对象，词条放在其中的列表里；部分版本还带有说明、排序算法和总词数。列表键及 SQL 表名以 [catalog.json](../data/catalog.json) 为准。

## 字段

| JSON 字段 | SQL 列 | 含义 |
| --- | --- | --- |
| 序号 | id | 当前词表的顺序，从 1 连续编号 |
| 原序号 | orig_id | 主词频表中的序号；存在于重排完整版和子集中 |
| 词频 | frequency | 原试卷语料中词形还原后的出现频次 |
| 单词 | word | 词条原始拼写 |
| 英式音标 | ipa_uk | 英式 IPA，带 `/…/`；多个读音用 `; ` 分隔，保留可选音如 `(r)` |
| 释义 | definition | 中文释义，经过人工初步校对 |
| 其他拼写 | variant | 其他拼写形式；可能为空 |
| 分类名称 | category | 117 个语义主题分类之一 |
| CEFR等级 | cefr | A1–C2；未匹配到时可能为空 |
| 学术词汇 | nawl | 是否命中 NAWL 参考词表，JSON 使用布尔值 |
| 高级词汇 | c1c2 | 是否命中 C1/C2 参考词表，JSON 使用布尔值 |
| 综合得分 | score | 智能排序评分 |
| 例句 | sentence | 英文句子、题干或短语，取自真题、新闻或公开语料 |
| 例句翻译 | sentence_cn | 与例句对应的中文；为空时直接省略，不显示占位文字 |
| 例句来源 | sentence_src | 例句出处，格式见 [来源说明](sources.md#来源字段格式) |
| 真题次数 | exam_count | 2005–2023 年考研真题词表中的出现次数 |

`词频`、`真题次数`、真题例句覆盖词数是三种不同口径，不能互相替代。字符串字段可能为 `null` 或空字符串，使用时应同时处理。

## 版本关系

- **完整词频版**：5530 词，按原试卷语料词频排序。
- **完整智能重排版**：同一组 5530 词，附 `原序号` 和顶层排序说明。
- **超课标词频版**：从完整词频版中去掉《普通高中英语课程标准（2017 年版 2020 年修订）》课标 3000 词，剩余 2697 词，按原词频顺序排列。
- **超课标智能重排版**：同一组 2697 词，从完整智能重排表筛选，保留相对顺序；仅重编 `序号`，其余字段沿用超课标词频版。
- **核心词频版 / 核心智能重排版**：均为考研真题核心词汇的 3050 词，词条集合相同，分别沿用词频顺序和智能重排顺序。

子集均重新连续编号；`原序号` 可回查 [完整词频版](../netem_full_list.json)。不要用不同版本的 `序号` 直接关联词条。

JSON 和 SQL 应同步维护。移动文件只改变路径，SQL 内的表名和字段顺序保持原样。
